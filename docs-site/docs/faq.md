# 常见问题与排错

以下汇总了日常使用与开发集成过程中最常见的问题解答：

### Q: 模拟器更新后需要重新执行挂载吗？

**A**: 若 MuMu 进行了大版本内核升级，建议重新运行一次 `install_bridge.py` 确保驱动与新内核 ABI 对齐。

### Q: 会被银行或金融类 App 检测为 Root 风险环境吗？

**A**: 由于采用了内核级按需提权机制，未被授予 Root 权限的普通 App 无法探查到任何 su 二进制文件或全局修改痕迹。


---

## 故障排查通用步骤

1. **核对运行环境版本**：确保您的 Node.js / Python 或浏览器版本符合最低兼容要求；
2. **检查控制台报错日志**：绝大部分配置错误或权限拒绝在控制台中都有清晰的行号与原因提示；
3. **提交 Issue 反馈**：若确认遇到底层 Bug，欢迎前往 GitHub 仓库提交复现用例与诊断日志。
