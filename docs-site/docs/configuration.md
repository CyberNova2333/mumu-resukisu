# 配置与使用指南

### 核心架构原理

1. **虚拟化层非侵入挂载**：
   无需修改只读的 `system.img` 分区，在 MuMu 虚拟化冷启动时由宿主机注入轻量级内核钩子；
2. **KSU Daemon 桥接**：
   在 Android Guest 用户空间拉起受信的 KernelSU 守护进程，接管系统调用级别的权限请求；
3. **白名单管理器**：
   配合 KernelSU 官方前端 App，精确针对每一个已安装的包名单独设定允许或拒绝 Root 提权。

---

## 生产部署建议

1. **环境变量保护**：切勿将包含真实密钥或 Token 的配置提交至版本库；
2. **优雅停机与超时**：建议将关键长任务的超时时限设置为合理范围，避免僵尸进程驻留；
3. **日志监控**：结合控制台输出建立定期检查机制，捕获潜在异常。
