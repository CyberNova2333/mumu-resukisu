# PID1 加载器

构建脚本为本次编译模块生成长度和 SHA256 常量。加载器只允许早期 PID1 路径进入；先检查模块完整性和精确235个未定义符号，再从当前核心符号表解析非零、非模块所有者地址。仅将允许的 ELF 符号绑定字段变为绝对符号，之后交给内核模块加载器。

模块的任何字节变化、缺少符号、零地址或其他模块提供的同名符号都会拒绝。固定模块参数为 `norc=1 preinit=0`，运行结束交给 `init.real`。源码未把本机实例、地址或任意外部模块作为可信输入。

`test-loader.c` 使用本次构建的模块验证摘要、ELF解析、缺失／零地址／模块所有者拒绝，以及仅允许绑定字段改变的边界。它不会装载模块。`build-native.py` 另执行非PID1宿主门禁，预期退出64。

加载器是本项目独立实现，使用 GPL-3.0-or-later；被加载模块保持其上游内核许可。构建和宿主测试成功不等于新构建已通过模拟器冷启动。
