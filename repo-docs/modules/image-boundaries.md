# 镜像变化与恢复边界

实例系统盘的“恢复”只针对本次安装前记录的私有差分盘。以一次安装为例：先保存源盘字节及摘要，再写入候选；运行后磁盘内容可能被系统合法修改，但磁盘身份与原备份仍须匹配，才允许恢复。数据盘中的管理器授权和脚本不在这份备份内。

组装时的约束与恢复时不同。组装必须证明允许分区以外的每个虚拟字节保持不变，还要求原有块映射、父盘身份与未允许修改的头部字段保持。恢复依赖已经建立的事务和原备份，不能要求运行过的候选仍与最初构建文件逐字相同。

| 状态 | 动作 | 拒绝条件 |
| --- | --- | --- |
| 写入前检查失败 | 保留当前盘，结束未写入事务 | 外部变化、运行中、基础盘改变。 |
| 写入一部分失败 | 在同一独占句柄中恢复原字节 | 恢复也失败时保留活动事务和错误。 |
| 安装中断，阶段未确定 | 只处理完整匹配原盘或候选的状态 | 未知部分写入不得猜测覆盖。 |
| 已安装后正常回退 | 停止绑定实例，恢复经过核验的原备份 | 实例身份、磁盘身份或备份内容不符。 |

实现位于 [镜像审计](../../src/mumu_resukisu/images.py) 和 [事务控制器](../../src/mumu_resukisu/controller.py)。验证使用 [Windows临时文件故障模型](../../tests/test_controller.py)；模型不代替设备启动验收。
